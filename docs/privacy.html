小刷记 力扣复习助手隐私政策

生效日期：2026 年 8 月 4 日

小刷记采用本地优先设计。当你在力扣中文站主动提交普通题目时，扩展会处理当前题目信息、判题结果和临时认证信息，并将复习记录保存在你的当前浏览器中。除实现该功能所必需的力扣同源 HTTPS 通信外，数据不会发送到开发者或其他第三方服务器；扩展不会保存你的提交代码、Cookie 或账号凭据。

1. 处理的数据

当你在已登录的力扣中文站普通题目页主动提交题目时，扩展会读取并在本机保存以下信息：

  • 题目 slug、中文标题、题号、难度、标签和题目地址；
  • 力扣提交 ID、Accepted 时间、触发方式和你的掌握程度；
  • 由 FSRS 生成的复习状态、下次到期时间和复习历史；
  • 提醒时间、通知开关、时区和备份格式版本；
  • 检测失败时的错误类型、发生时间和不含代码的诊断摘要。

扩展不会收集姓名、邮箱、手机号、支付信息、精确位置或提交代码，也不会持久化 Cookie、访问令牌或密码。扩展不读取 Chrome 浏览历史，不跟踪你在支持页面以外的浏览活动；只有在你主动提交支持的力扣题目时，才会处理并保存当前题目地址及上述复习数据。读取中文题目信息时，扩展会临时读取当前页面可见的 csrftoken，仅用于发送到 leetcode.cn 同源 GraphQL 接口的 X-CSRFToken 请求头；该值不会写入存储、备份或日志，也不会发送给开发者或其他第三方。

2. 使用目的

上述数据仅用于确认 Accepted、避免重复记录、安排间隔复习、展示本地统计、发送用户启用的提醒，以及帮助用户定位检测异常。数据不会用于广告、画像、信用评估或与扩展单一用途无关的目的。

3. 存储、传输与保留

题目、提交、复习日志和检测异常保存在扩展本地 IndexedDB；设置和通知幂等状态保存在 chrome.storage.local。扩展不使用 Chrome Sync，也不运营接收这些数据的服务器。

扩展仅通过 HTTPS 与 leetcode.cn 通信，以读取当前题目的中文元数据与结构化判题结果；请求由浏览器按力扣的同源规则附带当前登录状态，临时 CSRF 值也只用于该站点要求的 GraphQL 请求头。持久化数据保留到你在界面中删除单题、清空全部数据或卸载扩展为止。

4. 数据分享与出售

除提供核心功能所必需的 leetcode.cn 同源通信外，小刷记不会出售、出租、共享或转移用户数据，不会把数据传送给广告商、数据经纪商、开发者服务器或其他第三方。排期库随扩展代码在本地运行，不会把复习数据提交给其维护者。

5. Chrome 权限

  • storage：保存本地数据、设置和提醒状态；
  • alarms：在用户设定的当地时间安排提醒检查；
  • notifications：展示今日/逾期题目和待评估汇总；
  • https://leetcode.cn/*：在支持的题目页读取题目元数据、判题结果，并完成力扣要求的同源登录与 CSRF 校验。

扩展不申请 tabs、cookies、downloads、webRequest 或 unlimitedStorage。

6. 用户控制

你可以关闭通知、导出版本化 JSON 备份、删除单题或清空全部数据。导入备份前会完整校验；覆盖恢复需要二次确认。卸载扩展会由 Chrome 删除扩展本地存储。

7. 安全与远程代码

扩展不加载或执行远程代码，不包含遥测。由于力扣的站内接口可能变化，检测异常会明确显示，而不会通过页面文案猜测成功结果。

8. Chrome Web Store 用户数据政策

小刷记对通过 Chrome 权限和力扣同源接口获得的用户数据之使用，遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。数据仅用于扩展明确披露的单一用途：记录力扣中文站通过的题目并安排本地间隔复习。除为提供该用途所必需的力扣同源通信外，数据不会转移给第三方；不会用于广告、画像或信用评估；开发者及其他人员无法读取仅保存在用户浏览器中的数据。

9. 儿童隐私

本扩展不是面向儿童设计的服务，也不会主动收集任何人的可识别身份信息。

10. 政策更新与联系

如果数据处理方式发生实质变化，本页面会更新生效日期，并在扩展版本说明中披露。隐私问题请通过 Chrome Web Store 详情页列出的开发者联系渠道反馈。

“LeetCode”和“力扣”是其各自权利人的商标。小刷记与力扣官方无隶属或背书关系。
