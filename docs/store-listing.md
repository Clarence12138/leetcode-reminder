# Chrome Web Store 中文商店文案

## 基本信息

- 名称：小刷记 力扣复习助手
- 简短说明：自动记录力扣中文站 Accepted，用 FSRS 安排复习，让刷过的题真正留下来。
- 语言：简体中文（`zh_CN`）
- 分类建议：生产力工具
- 单一用途：记录用户在力扣中文站通过的题目，并用间隔重复安排本地复习。

## 详细说明

刷过一道题，不等于以后还会。

小刷记会在你登录力扣中文站并提交普通题目后，通过结构化判题结果确认 Accepted。确认成功后，你可以选择“未掌握、吃力、掌握、熟练”，扩展会根据 FSRS-6 间隔重复算法计算下次复习时间。

主要能力：

- 支持点击“提交”和 Command/Ctrl + Enter。
- 只记录明确 Accepted，不把“运行”、Wrong Answer 或超时误记为通过。
- 四档掌握程度，随时补评未评分记录。
- 今日到期、逾期、待评估一目了然。
- 每天当地时间定时发送汇总提醒。
- 按题目、难度、标签查看本地复习记录。
- 版本化 JSON 导入导出，便于迁移和备份。

隐私优先：

- 复习数据只保存在本机。
- 不保存提交代码、Cookie 或账号凭据。
- 不使用遥测，不出售或共享用户数据。
- 不加载远程代码。

当前仅支持 `leetcode.cn/problems/*` 普通题目页，不支持国际站、竞赛页或历史提交自动回填。

小刷记使用基于 FSRS 的间隔重复，不宣传固定、适用于所有人的“记忆曲线天数”。本项目与力扣官方无隶属或背书关系。

## 权限说明（商店表单）

### `storage`

保存通知设置、提醒幂等状态，以及本机复习数据的必要配置。长期题目、提交和复习日志保存在扩展自己的本地 IndexedDB 中，不使用 Chrome Sync。

### `alarms`

创建单次本地闹钟，在用户设置的当地时间检查今日到期与待评估数量。每次触发后重新计算下一次时间，减少夏令时或时区变化带来的漂移。

### `notifications`

在用户开启通知时展示“今日/逾期题目、待评估记录”的汇总。测试通知只表示 Chrome API 创建成功，不保证操作系统一定展示。

### 主机权限 `https://leetcode.cn/*`

仅用于普通题目页获取中文题目元数据和结构化判题结果。扩展不读取或保存提交代码、账号密码，也不保存 Cookie；读取题目信息时会临时读取页面可见的 `csrftoken`，仅用于 GraphQL 的同源请求头，不会落盘、导出、记录日志或发送给开发者及第三方。

## 隐私实践建议答案

- 是否收集可识别身份信息：否。
- 是否收集健康、财务、通信或位置数据：否。
- 认证信息：扩展会在本地临时处理 `csrftoken` 以完成力扣 GraphQL 同源请求；不会保存、导出、记录日志或传给开发者及第三方。提交商店隐私披露时应如实勾选“认证信息”。
- 是否收集网站内容：仅在用户主动提交题目时读取力扣返回的题目元数据和判题结果；不保存代码或页面正文。
- 数据是否出售、用于广告、信用评估或非核心用途：否。
- 数据是否传输到开发者或第三方服务器：否。
- 数据是否在传输中加密：扩展只通过 HTTPS 与 `leetcode.cn` 通信；长期数据不离开本机。
- 是否使用远程代码：否。
- 隐私政策：将 `docs/privacy.html` 发布到公开 HTTPS 地址后填写。
